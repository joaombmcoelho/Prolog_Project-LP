# A Computational Journey with Prolog - Logic for Programming (LP)

A Prolog programming project developed for the LP course (2025/2026) at Instituto Superior Técnico (IST), focusing on database inference, a wordle-like game, and constraint-based scheduling.
### Evaluation
* Final Grade 20/20
	* Automated Assessment: 18/18
	* Code Quality: 2/2

### Project Features
* Data Analysis: Statistics about students featuring health warnings and basic correlation math.
* Wordle Game: Core engine for the word-guessing in Prolog.
* Marathon Scheduler: Solves a movie scheduling problem using constraints.

### Compilation

Load the main project file in SWI-Prolog:
```prolog
swipl -s project.pl
```
